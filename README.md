# AUTOZONE — Tienda web de accesorios para vehículos

Proyecto educativo realizado con HTML5, CSS3, Bootstrap 5 y JavaScript.

## Incluye
- Diseño largo, adaptable a móviles y escritorio, con cuatro colores principales: negro, blanco/gris, naranja y azul como acento.
- Catálogo de 12 productos de ejemplo, búsqueda, filtros y orden por precio.
- Carrito demostrativo que calcula el total (no procesa pagos).
- Cambio de idioma Español/Inglés.
- Modo claro y oscuro.
- Animaciones de aparición, tarjetas con hover y cinta animada.
- Promociones los miércoles y viernes.
- Sección “Quiénes somos”, misión, visión y valores.
- Galería de imágenes.
- 15 herramientas de Google con enlaces.
- Mapa de referencia de Santa Tecla, La Libertad, El Salvador.
- Formulario de contacto que prepara un correo mediante `mailto:` y enlace general de WhatsApp.
- Formulario de novedades de demostración.

## Cómo abrir
1. Descarga y extrae la carpeta.
2. Abre `index.html` en el navegador o con Live Server en Visual Studio Code.
3. Para publicar, sube los archivos a GitHub y conecta el repositorio con Vercel.

## Personalizar antes de entregar
- Cambia la ubicación del mapa por la dirección real si el negocio tiene una.
- Sustituye el correo `contacto@autozone.example` por un correo real que controles.
- Cambia precios y productos de ejemplo en `script.js`.
- Las imágenes y Bootstrap Icons se cargan desde internet, por lo que requieren conexión.
- El formulario no envía datos a un servidor: abre la aplicación de correo. Para recibir mensajes dentro de una plataforma se debe configurar un backend o servicio de formularios seguro.
